Sub_HQ 로그인 → C-Card 템플릿(분류·코드) → 교재 연동 → 발급 결재 · 강사 크레딧 충전 · 매출

1. 로그인

  • 상단 방패(HQ) 아이콘으로 로그인 (Sub_HQ PIN / 총괄 PIN 동일 경로)
  • 지식·인력·관제 등 HQ 커맨드 메뉴를 사용합니다
  • 앱 홈 하단 사용안내로 역할별 안내서를 다시 열 수 있습니다

2. C-Card 템플릿

  1. 종목명 · 영문명 · 분류(스쿠버/프리/테크/스페셜티) · 연동 코드를 정확히 둡니다
  2. 다이버/강사 짝 종목은 코드를 분리합니다 (예: NITROX / NITROX_INST)
  3. 정렬 순서·앞·뒷면 배경을 등록하면 교육생 신청 목록·지갑·발급에 연결됩니다

3. 교재 연동

  • 필수 교재는 템플릿과 같은 분류·종목명·연동 코드로 저장합니다
  • 보조교자재는 코스 자동 지급 대상이 아니며, 관련 자격은 선택 사항입니다
  • 기념품은 교재 목록과 분리된 기념품 화면에서 관리합니다
  • 교육생 앱의 교재보기 / 내서재에 반영됩니다

4. 발급 · 강사 크레딧 · 매출

  • 발급 결재·강사 명부·매출 전표를 HQ 메뉴에서 확인합니다
  • 강사 크레딧 충전은 Sub_HQ(관리자) 역할입니다. 강사는 직접 충전할 수 없습니다 (1크레딧 = 1,000원)
  • 템플릿·교재 코드를 바꾸면 기존 연동이 어긋날 수 있으니 일괄 정리 후 저장하세요
