APDI SMART HUB · 강사 안내

버전 2026.10 · 상단 파란 배지 아이콘으로 공인 강사 로그인. 로그인 후 강사 관리실에서 신청 승인·발급·명부를 다룹니다.

한 줄 흐름
강사 로그인 → 교육 신청 승인 → 교재 지급 확인 → 발급 검토 → 명부·크레딧

1. 로그인 · 관리실

  • 상단 파란 배지 아이콘으로 공인 강사 로그인
  • 로그인 성공 시 강사 관리실(대시보드)로 이동합니다
  • 앱 하단 탭(홈·교재보기·내서재·C-Card·로그북)도 그대로 사용할 수 있습니다
  • 홈 하단 사용안내로 역할별 안내서를 다시 열 수 있습니다

2. 교육생 과정 승인

  1. 교육생이 홈의 다이빙 교육과정 신청으로 과정을 신청합니다
  2. 강사 관리실에 요청이 쌓이면 교육비·선수조건 확인 후 승인합니다
  3. 승인 시 템플릿과 같은 연동 코드·종목명의 필수 교재가 교육생 내서재에 연결됩니다

3. 발급 · 명부 · 기타

  • 교육생이 지식 평가 합격 후 발급을 의뢰하면 강사 측에서 확인·전달합니다
  • 강사 본인 자격은 C-Card(강사 로그인 상태)에서 확인합니다
  • 로그북 서명, 교재 구매(강사 계정), 교육 서류 · 전자서명 센터를 사용할 수 있습니다
  • 크레딧·발급 잔액은 관리실 안내에 따릅니다
