APDI SMART HUB · 강사 안내

버전 2026.10 · 상단 파란 배지 아이콘으로 공인 강사 로그인. 로그인 후 강사 관리실에서 신청 승인·발급·명부를 다룹니다.

한 줄 흐름
강사 로그인 → 교육 신청 승인 → 교재 지급 확인 → 발급 검토·상정(크레딧) → 명부·로그북 서명

1. 로그인 · 관리실

  • 상단 파란 배지 아이콘으로 공인 강사 로그인
  • 로그인 성공 시 강사 관리실(대시보드)로 이동합니다
  • 승인 대기 · 발급 확인 · 명부 요약을 한곳에서 확인합니다
  • 앱 하단 탭(홈·교재보기·내서재·C-Card·로그북)도 그대로 사용할 수 있습니다
  • 홈 하단 사용안내로 역할별 안내서를 다시 열 수 있습니다

2. 교육생 과정 승인

  1. 교육생이 홈의 다이빙 교육과정 신청으로 과정을 신청합니다
  2. 강사 관리실에 요청이 쌓이면 교육비·선수조건 확인 후 승인합니다
  3. 승인 시 템플릿과 같은 연동 코드·종목명의 필수 교재가 교육생 내서재에 연결됩니다

3. 발급 확인 · 상정

  1. 교육생이 지식 평가 합격 후 발급을 의뢰하면 강사 측에서 확인합니다
  2. 확인·본부 상정 시 해당 종목에 정해 둔 소요 크레딧이 담당 강사 잔액에서 차감됩니다
  3. 상정이 끝나면 지역본부 결재 후 교육생 C-Card에 반영됩니다

4. 크레딧이란

  • 1크레딧 = 1,000원
  • 발급 확인·본부 상정할 때 종목별 소요 크레딧이 담당 강사 잔액에서 차감됩니다
  • 잔액은 강사 관리실 상단/요약에서 확인합니다
  • 잔액이 0이면 상정할 수 없습니다 → 소속 지역본부에 충전을 요청하세요
  • 충전·조정은 강사가 직접 하지 않습니다. 지역본부(관리자)가 처리합니다
  • 차감 내역은 감사 원장에 기록됩니다

5. 로그북 사용 방법

  1. 하단 탭 로그북으로 들어갑니다
  2. 우측 상단 「강사 서명 모드」 스위치를 켭니다 (강사 로그인 필요)
  3. 교육생이 작성한 다이브 로그를 열고 내용을 확인한 뒤 서명(검증)합니다
  4. 서명 완료 로그는 “APDI 서명 완료”로 표시됩니다
  5. 서명된 공식 로그는 교육생이 마음대로 수정·삭제할 수 없습니다
  6. 본인 다이빙 기록도 같은 로그북에서 작성할 수 있습니다

6. 명부 · 기타

  • 강사 본인 자격은 C-Card(강사 로그인 상태)에서 확인합니다
  • 교재 구매(강사 계정), 교육 서류 · 전자서명 센터를 사용할 수 있습니다
  • 명부·교육생 목록은 강사 관리실에서 관리합니다
